# AI Examiner Agent

Демонстраційний вебзастосунок для проведення іспиту з основ NLP.

## Запуск на Render

- Runtime: Python
- Build Command: `pip install -r requirements.txt`
- Start Command: `python app.py`
- Environment: `GROQ_API_KEY` (секретний ключ з Groq Console, не завантажувати в GitHub)
- Web service: Free (за наявності в акаунті)

Публічна адреса Render зберігається між перезапусками. Безкоштовний сервіс засинає після простою.

**Важливо:** поточна демонстраційна версія зберігає результати у локальний `exam_results.json`, а незавершені іспити тримає в пам'яті. На Free Render ці дані можуть зникнути після засинання/перезапуску. Для постійного збереження слід підключити зовнішню БД.

**Доступ:** це навчальна демонстрація. Студенти розпізнаються лише за тестовим email. Не використовувати з реальними персональними даними або справжніми іспитами без автентифікації.
